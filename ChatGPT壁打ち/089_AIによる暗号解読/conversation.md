## 🔐 問題の本質：対応表をどうやって自力で作るか？

### 1. 暗号であると見抜く力（= 構造の気づき）
- **文字が一貫した記号に置換されている** → 替字式暗号（substitution cipher）
- 記号の種類に限りがある（26前後） → アルファベット26文字の可能性
- **間にスペースがある** → 複数単語である
- **記号が繰り返される** → 頻度分析が可能

### 2. 頻度分析（frequency analysis）
- たとえば "E" は英語で最も多く使われる文字  
→ 一番多く出ている記号を E と仮定
- 単語の構造：「_ E _」→ likely "THE"  
→ 短い単語に注目して仮定を立てる（THE, AND, YOU, etc.）

### 3. 試行錯誤で仮対応表を作る
- 頻度、語形、位置関係から **仮のアルファベット表を作成**
- 単語として成立するかを確認 → 一部でも正しく読めれば修正しながら進められる

---

## 🤖 AIのアプローチ（現代のホームズ方式）

AIが画像認識と推論を使って解読するには：

1. **画像処理**で個々の人形の姿勢・特徴を抽出（分類）
2. 各人形ごとに **ユニークな識別子を割り当て**
3. それらを並べて「文字列のように扱う」
4. **頻度・パターン分析**で仮の対応表を生成
5. **言語モデル**（GPTなど）で、単語として成立する可能性の高い文字列を予測
6. 結果が意味のある英語になるかどうかを検証

function encodeToFace(text) {

### 🔁 デコード関数（逆引き）

function decodeFromFace(faceText) {

}
