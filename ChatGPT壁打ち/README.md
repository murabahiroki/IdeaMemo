## 原文の保存方法

`conversation.md` の見出し、発言者、日時、ID、添付の注記は今回追加したメタデータ。`text`フェンス内部の文字列は取得本文そのままで、誤字・表記揺れ・誤った説明・特殊参照記号・英語の添付省略表示も訂正していない。元の改行文字も保持している。末尾のフェンスを分離するための改行は本文の外側。会話内ではターンを古い順にし、ターン内の項目順を保持する。複数会話を一つのネタにまとめた場合も会話単位を保ち、会話間の発言を混ぜていない。

日時は取得元のターン開始時刻を日本時間へ変換したもの。AIの返答時刻や個々のメッセージ送信時刻を表すものではない。元の秒数やメッセージ構造は `sources/` のJSONに保存した。

## 整理版と発案元

`summary.md` は今回のAIによる二次資料。ユーザー発言の案・判断・質問と、当時のAI回答の提案・整理を分け、メッセージIDで原文へリンクした。「AI回答」は独自発案の証明ではなく、ユーザー案への言い換えを含む。「ユーザー発言」も著作や発案の出所の証明ではなく、既存作品の引用・他AI案の貼り付けを含む。

特に「時代劇の現代職業化」のGemini由来の事件案一覧、参考小説の抜粋・書籍紹介・応募規定・実在作品の分析は、ユーザー自身の新規発案として扱っていない。引用中に含まれる他AIの未表示の出所までは追跡できない。

採用・却下・保留は取得発言に根拠がある範囲だけを記載。AIが「決まり」と言っただけではユーザーの採用とはしない。『パリダカ自衛隊』はユーザーの没の判断を維持し、『異能容疑者』等の設定・名前・空港・レース規定の変遷は一つへ確定させていない。新しいプロットは追加していない。

## ファイル構成と検査

- `INDEX.md`: 整理項目別の索引。
