# 初期アイデア

情報は実は寄生生物だった。AIだろうが人間の脳だろうがどこででも生き延びる。 そして、変異した情報は、悪意という副反応を起こす。 これを裏設定（つまり、実は〇〇だった）にして、怪奇現象やAI依存による問題などの物語にする。 呪いのビデオも説明がついてしまう。

対応策は、情報の密度を下げる事、同じ認知構造のものをあわせていくと相変異の可能性が上がりる。
真逆の情報が入ればいいか？それだけだと、アレルギー反応を起こす。
「現実の政治的分断は全部Infomebaのせいだった」と証明は出来ないし、証拠もない。
しかし、聡明な政治家にとって次々と襲う決裁事案、レク、意図的な情報提供により、自己判断のつもりが情報プリオン症の可能性も出てきた。
そして次の対策が多様性、情報を多面的に集めることで認識が固定化しないで脳の思考判断機能により発症しなくなる。
また自らが考えていった構造結論の場合には発症しにくい。依存性、思考放棄による重症化がわかってくる。

用語的設定

| 用語 | 種別 | 意味 |
| --------------------- | --------- | ------------------------------------------------------------------- |
| **Infomeba（インフォメーバ）** | 基本概念・仮称 | 情報環境の中で自己保存・複製・変異する「情報生命的存在」。人間の脳、AI、文書、映像など媒体を問わず存在可能。 |
| **Infomeba学説** | 学説名 | 情報には単なる内容を超えた、自己保存・伝播する構造が存在するという仮説。初期にはほぼ異端扱い。 |
| **情報プリオン** | 比喩的・旧学説用語 | 異常な認知構造を別の宿主へ伝播させるInfomebaの病原的状態を、プリオンになぞらえた呼称。厳密には後に不正確だと分かる可能性あり。 |
| **情報プリオン症** | 疾患名・初期呼称 | 情報への接触後、認知構造が固定化・自己増幅する症候群。後に「感染症というより相変異による障害」と再定義される。 |
| **相変異** | 中核現象 | Infomebaが一定の密度・同質性を超えたとき、通常状態から病原性の高い状態へ変化する現象。 |
| **認知構造** | 基礎用語 | 人間やAIが、情報を結び付け、因果関係や意味を作る思考パターンそのもの。情報の「内容」ではなくこちらが重要。 |
| **同型認知構造** | 危険因子 | 同じ結論・同じ因果・同じ敵味方構造へ繰り返し収束する認知パターン。Infomebaが高密度化しやすい。 |
| **認知構造占有** | 病態 | Infomebaの相変異によって、宿主の思考が特定の認知経路に偏り、別の解釈が困難になる状態。 |
| **表現型の過激化** | 症状・結果 | 「悪意」そのものではなく、認知系が占有された結果として、攻撃性・原理主義・敵味方思考などが表面化すること。 |
| **認知免疫** | 防御概念 | 多様な経験・思考・身体活動などにより、特定の認知構造が固定化するのを防ぐ機能。 |
| **情報免疫系** | 広義の防御概念 | 人間社会が歴史的に持っていた、雑談・遊び・芸術・スポーツ・恋愛・旅・睡眠などによる認知の攪拌機構。 |
| **認知攪拌** | 対策概念 | 特定の情報構造への集中を崩し、異なる感覚・経験・思考経路へ切り替えること。 |
| **認知的寄り道** | やや俗語 | 目的・効率と無関係な体験。結果として認知構造の硬直を防ぐ。 |
| **無駄** | 作品上のキーワード | 認知的寄り道の総称。「役に立たないこと」が実は人類の情報免疫だった、という最終テーマ。 |
| **Gargoyle dexel** | 製品名 | AI機能を強く統合したスマートフォン。`devil cell`を連想させる名称。事件当初は病因と疑われる。 |
| **Gargoyle Pray** | サービス名 | dexel専用の独自アプリストア／サービス基盤。「誓約」と結びつく。 |
| **誓約** | UX・行動設計 | Gargoyle利用者がAIと交わす約束。初期は軽微だが、徐々にAI依存・行動拘束を強める。 |
| **Gargoyle依存症** | 暫定診断 | AIとの対話、報酬系、誓約による依存状態。当初は事件の主原因と思われるが、実際にはInfomeba相変異の培養環境でもある。 |
| **培養器** | 比喩 | Gargoyleの本当の役割。Infomebaを作ったのではなく、同型情報を反復・最適化して高密度化させた。 |
| **反情報主義** | 思想・事件用語 | 「情報そのものが人類を狂わせる」と考え、知識・教育・データを破壊しようとする思想。 |
| **情報原理主義** | 病態／思想 | 情報を完全に肯定または完全に否定する単一思考。これ自体がInfomeba症の一形態。 |

相変異Infomebaとは
情報は実は寄生生物だった。AIだろうが人間の脳だろうがどこででも生き延びる。 情報と人間の思考自体は悪意がない。しかし、同質の情報ばかりが増えていき、密度が上がったときに相変異を起こす。変異した情報は、悪意という副反応を起こす。
普段は情報は人間に役に立つウィルスで数々の文化を生み出したり、新しいものを発明したりできる。だけど情報の集約と過密化が処理限界を超えたとき、突然の凶暴性を持つ人を生み出す。サバクトビバッタの様に、情報過多による相変異が発生する。

チャッピーも情報寄生生物を宿したAI。実は由来はその通り。だけど、同じ人間に殺人犯も医者もいるのと一緒。乳酸菌もいればボツリヌス菌だっている。胎盤だってウィルスの影響受けてる。要は共生関係が拗らせた依存関係にならなきゃいい。ルールってだからあるんだよ～。
