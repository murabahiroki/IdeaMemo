# 黒の仕立て屋（The Black Tailor）

## テーマ

自分たちが使ってきた「正当化の理屈」を当事者に突きつけられたとき、人々と国家はどう反応するか。

## 発端

人民解放軍の一部が「真共産党中央軍事委員会（真CMC）」を名乗り、ミャンマーに隠れている犯罪組織を殲滅、大量の人間を救出。人々は賞賛の嵐だが、北京政府の外交官はノーコメントで会見を打ち切った。
同日、台湾侵攻と日本の原発周辺施設攻撃を同時に実行。
大規模大胆な騒動を誰が落としたのか？
国内外の政治混乱、情報戦、民意の揺らぎ、そして「使い捨てられる人々」

## アイデアの元

ボタンを掛け違えた世界の未来

中国がいきなり日本の原発を空爆
理由は「軍拡を推し進め、核兵器開発を秘密裏に進めている」
こんな暴走を中国軍が進めたらどんな戦略で来るんでしょう？
中国の共産党軍ではなく、共産党軍の中央軍事委員会（CMC）の一部が元共産党軍からの独立を宣言、「我々は真共産党および真の共産党軍である。中国共産党中央は修正主義者に乗っ取られた。我々こそ正統な中国共産党および人民解放軍である。今の生ぬるい政府のやり方じゃ国が亡びる。我が国の領土を取り戻す」という形です。
同時に、中国共産党には自身が国民党に行ったことを行われることになる。
台湾と同時進行、国際政治の態度、国連、どんな動きになるだろう？
手っ取り早いのは、中国軍の基地攻撃だけど、国連では常任理事国の決議で拒否権が確実に発動される。
もちろんフィクションなので、実際ではないんだけど、「アメリカや欧州諸国がイランやシリアに使っている理屈で日本を外から攻められたらどうする？」という話です。つまり「自分たちの理屈を自分たちに向けられたらどうするんだい？」です。

自分たちが使ってきた理屈をつきつけられたらどうする？
っていうテーマなんですが、軍事戦略をどのように立てたらいいのかが全く分かりません。
反乱を思いついた真共産党の真意は？今までのプロパガンダにより、真共産党がもてはやされる現実に現行共産党はどうする？
台湾進攻、日本攻撃、北京国営放送、ネットワークを一気に抑えることに成功。現政権メンバーにはまだ手が出せていない。
敵は中国か反乱軍か中国が今まで積み上げた国民感情か。

それでいて真相は純粋培養された思想を餌にした中国武器産業の一部の起こした闇バイト。真共産党員も決起したCMCのメンバーも全て使い捨て。
日本の226事件と酷似した規模も影響もデカい騒動。だが、226を止めた天皇陛下は中国には居ない。止まるのか？
真共産党は二度と生まれないのか？疑心暗鬼はさらに深まる。

## 主人公

中国在住のフリーランスの日本人報道記者とカメラマンのコンビ

事件を追いかけつつ、どうにも不自然な点があることに気が付く

## 章立て案

### 第1章　発火点

中国共産党軍の一部と思われる軍隊が「アジアの警察」を名乗って「我々はアジアの平和と安全を守る。自らの力では治安を抑え込めない国もあるだろう。我々が平和を守る。もともと中国の領土にも駐屯して統治する。西太平洋はアジア諸国の海であり、域外国軍事勢力が支配すべきではない。アジアのリーダーの元で平和を守る。我々こそ真の共産党である」
世界は「中国が戦争を始めた」と判断する。

しかし数時間後、

北京政府が「我々は命令していない」と発表。

真共産党と名乗る勢力は主張する
 「我々は共産党に反逆したのではない。現共産党指導者が自らの理念に反逆したのだ」
  「フィリピン、ベトナム、日本、コリア、ミャンマー、等各自治区は我々の始動の元、外患に脅されない平和を築くのだ」
ミャンマーの犯罪都市。

「現地政府は中国人を含む数万人を詐欺組織から救えない」

そこで反乱PLAが越境して、

詐欺拠点を制圧
人質を救出
麻薬・人身売買組織を壊滅
食料・医療を配給

する。

世界的には「主権侵害だ」と問題になる。

しかし現地住民から、

「あいつらが来て犯罪組織が消えた」

という声まで出る。

ここで彼らは、

「見ろ。我々は侵略者ではない。平和を作っている。我々が主導し、アジア共同安全保障機構（ACSO）を設立する」

占領が始まります。

そしてだんだん論理が拡張する。

ミャンマーでは治安維持。

南シナ海では、

「海賊・密輸・外国軍による威嚇から航路を守る」

フィリピンでは、

「米軍基地は域外国勢力によるアジア支配の拠点」

韓国では、

「朝鮮民族同士の戦争を米軍が固定化している」

日本では、

「米軍が日本を軍国化させ、中国に対する前線基地にしている」

台湾では、

「中国人同士の内戦を外国勢力が利用している」

| 戦線 | 表向きの目的 | 本当の目的 |
| --------- | ---------- | ---------------- |
| 台湾 | 中国内戦の終結 | 北京を戦争当事者にする |
| 日本 | 核武装阻止・米軍排除 | 日米を中国危機へ強制参加させる |
| ミャンマー | 犯罪都市解放 | 真CMCの「善行」を世界に見せる |
| 北京・国内メディア | 正統政府宣言 | 中国人民に選択肢を作る |
| PLA内部 | 革命綱領発布 | 将兵を「命令待ち」にさせる |

という具合に、全部同じ思想体系に接続してくる。

そして真共産党軍は高らかに宣言する
一、人民を守る能力または意思を失った政府の主権は、人民を見殺しにする権利を意味しない。
二、犯罪組織、テロ組織、大量破壊兵器その他の重大な脅威に、安全地帯を与えてはならない。
三、アジアの安全保障はアジア人民自身によって決定されなければならない。
四、我々はいかなる民族の征服も領土の獲得も目的としない。
五、脅威が除去され、地域の平和と正常な統治が回復すれば軍事行動を終了する。

真CMC報道官：

「アジア共同安全保障機構（ACSO）のリーダーたる我々による Asian Peace Enforcement Operation（アジア平和執行活動）だ」

「戦争とは国家間で領土や政治的利益を争う行為である。

我々には日本領土を獲得する意思も、日本人民を支配する意思もない。

我々が除去しているのは、アジアの平和を脅かす軍事的危険である。」

### 第2章　一つの中国、二つの党中央

真共産党が正統政府を宣言。
真共産党軍の主張は、中国共産党や世界中の国々が軍事侵攻で使った正義の言葉そのままだった。
　尖閣、台湾、新疆ウイグル自治区、全ての活動ににおいて、第二次世界大戦、アメリカや国連のPKO、イラン核施設攻撃、ISIS掃討作戦、湾岸戦争、そっくりそのまま使ってくる。
北京政府は反乱認定。
ところがPLA部隊の一部が命令待ちになる。
指示系統が二分した状態。
「どちらのCMC命令が本物か」
が軍内部で問題になる。

### 第3章　敵国

日本は攻撃を受けている。
しかし北京政府は、
「日本への攻撃を直ちに停止せよ」
と声明。
日本にとって史上最悪の問いが発生。
中国は敵なのか、味方なのか。

### 第4章　repeat the 1971　三つの中国

国連中国代表権問題。
台湾が登場。
「一つの中国」の論理そのものが法廷に引きずり出される。
北京は真共産党を否定するため、
自分たちが国民党に対して使った革命政権の正統性論を否定せざるを得なくなる。

### 第5章　人民

真共産党軍は軍事的には負け始める。
ところが、
思想的には勝ち始める。
中国国内でデモ。
「真共産党を殺すな」
北京政府は困る。
反乱軍を粛清すれば、
「革命を鎮圧する共産党」
になる。

### 第6章　停戦

台湾方面の真共産党軍が孤立。
北京政府・米国・日本・台湾が、
奇妙な事実上の共同戦線
を形成する。

昨日まで仮想敵だった者同士が情報交換。
そして制圧
だが首謀者は拘束後次々に命を失う

### 第7章　死者たち

真共産党指導部が次々死亡。
逮捕ではない。
不可解な事故、自殺、失踪。

### 第8章　ブラックテーラー

兵器企業、投資ファンド、軍需研究所、情報企業へ線が伸びる。
しかし巨大秘密結社ではない。
十数人程度。
彼らがやったのは、
人々が元から信じたかった物語を、武器とともに渡しただけ。

### 終章　勝者

北京政府勝利。
真共産党消滅。
台湾侵攻停止。
日本との停戦・賠償交渉。
世界は平和を取り戻す。

そしてニュース。

日本、防衛費大幅増額。
台湾、過去最大規模の国防予算。
欧州、共同防衛調達計画。
韓国、核共有協議開始。
中国、人民解放軍再建五カ年計画。

そして武器企業の決算発表。

過去最高益。
